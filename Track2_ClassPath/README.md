# ClassPath · 课路

**赛道二：Reverse Product Innovation ｜ 作品提交包**

> 把「小红书」拆到价值逻辑层，得到一条公式 `V = (E × S × U) / C`，
> 再用它做了一个新东西：**不评课，只交"选课路径"**。

---

## 一、这是什么

| | |
| --- | --- |
| **逆向对象** | 小红书 |
| **逆向结论** | 它卖的不是内容，是**"决定的代理权"** |
| **可迁移公式** | `V = (可执行度 E × 处境相似度 S × 决策紧迫度 U) / 检索与验证成本 C` |
| **迁移领域** | 高校选课 |
| **原创点** | 把最小信息单元从 **Course（一门课）** 换成 **Path（一条路径：目标 + 一组课 + 时间预算 + 为什么）** |
| **产品取舍** | 继承价值逻辑，**拒绝注意力逻辑**：不做无限流、强制写"这条不适合谁"、内置时间预算护栏 |

完整推理见 [`01_逆向设计报告.md`](01_逆向设计报告.md)。

## 三、怎么运行

**方式一（最简单）**：双击 `prototype/index.html`，浏览器直接打开，无需服务器、无需联网。

**方式二（手机演示）**：把 `prototype/` 目录用任意静态服务器托管，手机同网段访问。
例如在本目录执行 `python -m http.server 8080`，手机打开 `http://<电脑IP>:8080/prototype/`。

**深链**（演示时可直接跳到某一屏，也方便截图）：

| 链接 | 屏幕 |
| --- | --- |
| `index.html` | 首屏：选目标 + 调时间预算 |
| `index.html#list` | 路径列表（按处境相似度排序） |
| `index.html#detail=p1` | 路径详情（可执行字段 / 为什么 / 不适合谁） |
| `index.html#draft=p1,p5` | 课表草案（时间冲突 + 学时超支告警） |

## 四、演示动线（约 60 秒）

1. 首屏选「保研冲绩点」，滑杆停在 **20 h/周**。
2. 列表里第一条相似度 **96%**，但它不是被照抄最多的那条——说明排序依据是处境而不是热度。
3. 进详情：看「为什么这样排」「逐门课的可执行字段」「这条路径不适合谁」。
4. 点「照抄这条路径」→ 草案页立刻给出 **1 处时间冲突**（计算机组成原理 × 体育，周一第 3/4 节）和**周学时超支**（21h vs 20h）。
5. 收尾一句：**浏览到这里，才真正变成一个决定。**

## 六、技术说明

- **形态**：单文件 HTML + 原生 CSS/JS，无框架、无构建、无外部依赖（离线可用）。
- **数据**：8 条示例路径，课程与分数均为**虚构示意**，不代表任何真实院校。
- **相似度**：`目标命中（权重最高）+ 周学时接近度 + 被照抄量（弱权重）`，最终归一化到 0–99。
- **冲突检测**：每门课带 `slots:[[星期, 节次]]`，照抄多条路径时按「课程对 + 星期」聚合冲突节次。
- **护栏**：周学时 > 预算、学期混排、早八 ≥ 3 门、学分 < 15，分别给红/黄牌。
- **海报渲染**：Chrome 无头渲染 `poster.html` 为 PNG 与 PDF，字形与排版与源文件完全一致。

## 七、已知边界

- 报告中的"观察"来自设计者自省与同学间讨论，**不是统计抽样**；三条核心假设（H1–H3）写在报告 §10，尚未用真实用户验证。
- 示例路径数据是虚构的。真实上线需要：院校课程库授权、作者实名/匿名策略、回填激励机制。
- 二维码位为占位，正式提交前替换为原型部署地址或演示视频链接。
