01

五个"忍不住"的瞬间

behaviour, not features

不写功能，只写行为切片。这五条是我们自己使用时记下来的：

  1. 决定悬空时打开。午饭吃什么、买哪款耳机、周末去哪——不是"我想看内容"，是"我有个决定没做"。
  2. 30 秒内要一个结论。首图就是结论，标题就是问题（"200 块以内送男朋友"）。用户在接受信息前，先接受了一个判断。
  3. 只信"和我像的人"。同龄、同预算、同城市、同肤质。官方说明和专业测评反而排在后面——权威在这里是失效的。
  4. 收藏 ≠ 喜欢。收藏夹是一个"待办清单"，不是"喜欢清单"。
  5. 搜索框里是问题，不是关键词。输入的是处境："大一 想保研 但数学不好"。
这五条指向同一个结论：用户来这里不是为了"看"，是为了不用自己判断。
02

四层拆解

function → interaction → psychology → value
层级现象机制被满足的需求
功能层图文笔记、双列瀑布流、搜索、收藏内容供给 + 检索 + 归集找到别人的经验
交互层首图即结论、标题即问题、收藏一键把比较成本与承诺成本同时压到接近零快速收敛选项
心理层决策外包、身份相似信任、收藏夹=待办把"我要判断"换成"我认领一个判断"降低判断焦虑
价值层——用同类人的可执行经验，替代权威的抽象标准把决策变成"检索 + 照做"
03

可迁移的那条公式

the only portable part
FORMULA

V = ( E × S × U ) / C

E 可执行度 · S 处境相似度 · U 决策紧迫度 · C 检索与验证成本。乘法结构：任何一项为零，整体价值归零。

TEST

抄对了吗？

E 高 S 低 → 教程，看完就走；S 高 E 低 → 吐槽社区，情绪散完就散。只有两者同时高，才是分子。

04

三条设计律

what we actually copied
律 1

交付可执行单元

给"价格 89 / 店在二楼 / 别点招牌"，不给"这家不错"。

律 2

信任来自相似

必须携带处境标签，并保留瑕疵感。权威榜单会让 S 归零。

律 3

给一个零成本承诺

收藏的成本≈0，却把内容搬进了"我的计划"。

05

迁到了哪里
