## 二、图像生成：四种模式

主页点右上角状态胶囊（`LOCAL ASSETS` / `OFFLINE …` / `LIVE …`）打开设置：

| 模式 | 要密钥 | 说明 |
| --- | --- | --- |
| **本地素材**（默认） | 否 | 内置 12 张由图像生成 API 产出的图，离线可用、永远成功 |
| **离线生成** | 否 | Canvas 程序化绘制徽章/海报，每次结果都不同，断网也能跑 |
| **免费直连** | 否 | 走 `image.pollinations.ai` 公共接口，真实 AI 出图；公共配额有限，忙时 402/503，失败自动回退 |
| **自建端点** | 是 | 任意 OpenAI 兼容 `/images/generations`，可接 AMD 或自己的中转 |

「测试一次」会当场跑一次并显示结果与耗时，不必回装置里试。

自建端点的请求体：

```json
{ "model": "<Model>", "prompt": "<装置拼出的提示词>", "n": 1,
  "size": "1024x1024", "response_format": "b64_json" }
```

返回 `data[0].b64_json` 或 `data[0].url` 都接受。浏览器直连第三方接口常见 CORS 限制，
被拦时用一台能转发的中转（本地脚本或云函数）把密钥留在服务端。

所有配置只存在 `localStorage`，不上传。

## 三、街机键与快捷键

右下角那颗会呼吸的绿色圆钮永远只做「当前该做的那一件事」：领盲盒 / 开箱 / 刷新 /
开始专注 / 守住 / 清一块……键面文字随状态实时变化。

按下时有下沉手感、冲击波、低频 `thunk` 音、轻微振动。

| 键 | 动作 |
| --- | --- |
| `D` | 按一下街机键 |
| `1`–`5` | 直接切到第 N 个装置 |
| `C` | 进入案例子页 |
| `Esc` | 收起弹窗 |

## 四、声音

全部由 Web Audio 实时合成，**0 个音频文件**：tick / click / thunk / whoosh / unlock /
reward（大三和弦琶音，稀有度决定音数）/ fail / dissolve，每个装置一条不同基频的底噪。

顺序是刻意的：**先用滴答制造稀缺，再用和弦做记忆锚定**——老虎机的顺序，接到你自己的行动上。

## 六、边界

1. 五个装置是原型，不是临床或行为干预产品，没有健康效果声明。
2. 悬念器「45 秒」、契约「90 秒」是为演示压缩的，界面上已标注。
3. 清理器的验证是自觉勾选，不是图像识别——没做的不写成做了。
