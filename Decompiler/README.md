# 反编译实验室 · The Decompiler

一个站点，两件作品，一条方法论。

```
拆机制  →  换分母  →  验证它
```

- **上半场**：五个 30 秒能玩完的机制原型（`index.html`）
- **下半场**：一个真的落到场景里的产品（`case.html` → ClassPath 课路）

---

## 一、打开方式

### 1. 本地直接打开

双击 `index.html`。全部为静态文件，无需构建、无需联网。

> 子页面 `case.html` 内嵌了 ClassPath 原型（`../Track2_ClassPath/prototype/index.html`）。
> Chrome / Edge 下 `file://` 可以直接内嵌；若你的浏览器禁止跨目录 iframe，
> 页面里留了「在新标签打开完整原型」的按钮。

### 2. 让别人也能打开（局域网）

在**工作区根目录**（不是本目录）起一个静态服务器，已经为你起好了一份：

```powershell
cd <workspace>\site
python -m http.server 8080 --bind 0.0.0.0
```

然后别人访问：

| 页面 | 地址 |
| --- | --- |
| 入口页 | `http://<你的局域网IP>:8080/` |
| 实验室（五个装置） | `http://<你的局域网IP>:8080/Decompiler/` |
| 案例子页 ClassPath | `http://<你的局域网IP>:8080/Decompiler/case.html` |
| 课路原型（独立） | `http://<你的局域网IP>:8080/Track2_ClassPath/prototype/` |

`site/` 目录里用 Junction 指向真实目录，所以不会复制文件；改源码即时生效。

**如果别人打不开**：Windows 防火墙默认挡掉入站端口。用管理员 PowerShell 执行一次：

```powershell
netsh advfirewall firewall add rule name="Decompiler Lab 8080" dir=in action=allow protocol=TCP localport=8080
```

### 3. 让不在同一网络的人也能打开（公网链接）

需要一条隧道。任选其一：

```powershell
# Cloudflare 快速隧道（无需注册，输出一个 https 链接）
cloudflared tunnel --url http://127.0.0.1:8080

# 或 ngrok
ngrok http 8080
```

两者都需要先装对应工具。Cloudflare 的链接是临时的（每次重启会变），
且**任何人都能访问**——演示结束后记得关掉。

## 二、那个「街机键」和快捷键

右下角那颗会呼吸的绿色圆钮是**唯一的交互键**——它永远只做"当前该做的那一件事"：

| 当前装置 | 键面文字 | 按下去发生什么 |
| --- | --- | --- |
| 行动盲盒（待开始） | 领 一 个 | 抽任务，进入 30 秒真实倒计时 |
| 行动盲盒（计时中） | 还在计时 | 提前按会被拒绝：奖励只认完整时间 |
| 行动盲盒（可开箱） | 开 箱 | 生成徽章 + 稀有度和弦 + 粒子 |
| 自我回音壁 | 刷 新 | 读取文本框 / 语音，渲染情绪海报 |
| 悬念阻断器 | 开 始 专 注 | 45 秒；中途切走页面会被判负 |
| 反内卷契约 | 先 签 名 / 守 住 了 | 签名前会拦一下；倒计时中按下即"守住" |
| 认知清理器 | 清 一 块 | 依次清掉四块噪点 |

按下时有：下沉 8px 的实体手感、一圈扩散的冲击波、低频 `thunk` 音、以及一次轻微振动（支持的设备）。

**快捷键**（输入框内不触发）：

| 键 | 动作 |
| --- | --- |
| `D` | 按一下街机键 |
| `1`–`5` | 直接切到第 N 个装置 |
| `C` | 进入案例子页 ClassPath |
| `Esc` | 收起弹窗 / 抽屉 |

### 页面之间的转场

- **切装置**：带方向的滑动——往右走（1→3）旧内容向左退、新内容从右进；往回走则相反。所以来回切的时候，方向感是对的。
- **主页 ↔ 子页**：用 View Transitions（`@view-transition: navigation auto`），旧页轻微上浮淡出、新页从下方落定；不支持的浏览器自动退化为普通跳转。
- **滚动入场**：区块位移归位，不做透明度（任何环境下内容都不会消失）。
- 系统开了「减少动态效果」时，以上位移全部关闭。

## 四、两个部分怎么接在一起

| | 实验室（五个装置） | 案例（ClassPath） |
| --- | --- | --- |
| 粒度 | 单次机制，30 秒 | 完整产品，一整个学期 |
| 被劫持的机制 | 斯金纳箱 / FOMO / 悬念 / 损失厌恶 / 完成强迫 | 决策外包（刷别人的结论） |
| 分母 | 你的行动 / 专注 / 守信 / 秩序 | 你自己走过的那条路 |
| 证明什么 | 方法论可复用 | 方法论能撑起产品 |

两者共享同一句话：**分子一模一样，只换分母。**

## 五、四条诚实边界

1. 五个装置是原型，不是临床或行为干预产品，没有任何健康效果声明。
2. 悬念器「专注 45 秒」、契约「24 小时」都是为演示压缩的，界面上已标注。
3. 清理器的验证是自觉勾选，不是视觉识别——没做的不写成做了。
4. 课路的课程与分数是虚构示意数据；报告第 10 节列了三条待验证假设。
